**Excel Sales Dashboard :**

This repository contains a dynamic sales dashboard created entirely in Microsoft Excel. The project is designed to analyze and visualize complex sales data to derive actionable insights.

* **Key Performance Indicators (KPIs):** Total Sales, Total Profit, Profit Margin, and Total Orders.
* **Time-Series Analysis:** A trendline chart showing sales performance over months, quarters, and years.
* **Categorical Analysis:** Charts breaking down sales by Product Category, Sub-Category, and Region.
* **Customer Insights:** A view of the Top 10 customers by sales and profit.
* **Interactive Controls:** The dashboard is fully interactive, using Slicers and Timelines to filter the data dynamically.

**🛠️ Tools Used :**
* **Microsoft Excel:**
    * Pivot Tables & Pivot Charts for data aggregation and visualization.
    * Slicers & Timelines for interactive filtering.
    * Formulas & Calculated Fields for creating custom KPIs.
    * Data Cleaning and preparation techniques.

**🚀 How to Use :**
1.  Download the `Sales Dashboard.xlsx` file from this repository.
2.  Open the file in a modern version of Microsoft Excel (2016 or newer is recommended).
3.  Enable content/editing if prompted.
4.  Use the slicers on the dashboard to filter and explore the data.
